# Security policy

## Секреты

- Настоящий `OPENAI_API_KEY` хранится только в локальном `.env` или в secrets
  окружения деплоя.
- `.env` и `.streamlit/secrets.toml` исключены из Git.
- В `.env.example` должны находиться только безопасные шаблонные значения.
- Ключ нельзя публиковать в issue, pull request, README, логах или скриншотах.

Если ключ случайно оказался в Git, его нужно немедленно отозвать в OpenAI,
создать новый и только затем очищать историю репозитория.

## Сообщение об уязвимости

Не публикуйте данные об уязвимости в открытом issue. Свяжитесь с владельцем
репозитория через его GitHub-профиль.
